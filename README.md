## 📖 About

This list is **comprehensive and production-first**. It is a working **job-search operating system** for anyone looking for a role, hiring, or advising job seekers — engineers, product managers, designers, executives, recruiters, career coaches, and founders.

Every section opens with a **primer** (the mental model you need), then lists the **platforms, tools, and services** professionals actually use. Where a category has an obvious default, it is marked with ⭐.

**Legend:** ⭐ widely adopted default · 🔓 open source · 💰 commercial / paid tier · ☁️ managed service · 🆓 free · 🏢 agency · 🎯 niche

> **How to use:** Start with [Job Search Fundamentals](#job-search-fundamentals), pick 2–3 boards from [Global Job Boards](#global-job-boards) + your [Region](#regional-job-boards) (see [UAE & Gulf](#uae--gulf-gcc) and [Saudi Arabia](#saudi-arabia--dedicated) first if you target the Gulf), add one [Aggregator](#job-aggregators--meta-search), prep with [Interview Guidelines](#interview-guidelines), and ship with [CV Services](#cv--resume-services). All applications here are **manual** — apply on the company ATS or the board itself, track in [Manual Application Tracking](#ats-optimization--manual-application-tracking), never via bulk auto-apply bots.

## Job Search Fundamentals

> The job market is a **matching problem under information asymmetry**. Companies pay for distribution (job boards), curation (agencies), and signaling (referrals). As a candidate, you win by **maximizing surface area** (where you appear) and **signal quality** (how you appear). 70–80% of roles are filled via network before they hit public boards — treat every application as a pipeline, not a lottery ticket.

### Key concepts
- **Funnel math** — 100 applications → 10–15 screens → 3–5 interviews → 1 offer is normal. Track conversion per stage, not just volume.
- **ATS (Applicant Tracking System)** — Greenhouse, Lever, Workday, Taleo filter before a human sees your CV. Keyword match + formatting matters.
- **Referral leverage** — a referral is 3–4× more likely to get an interview than a cold apply. Prioritize warm intros over spray-and-pray.
- **Three channels** — **Inbound** (boards/aggregators), **Outbound** (direct outreach to hiring managers), **Network** (agencies, communities, alumni).
- **Two clocks** — **Time-to-apply** (new postings get most attention in first 48h) and **Time-to-follow-up** (7 days without reply → nudge).
- **Compensation bands** — base + bonus + equity + benefits. Always research bands *before* the recruiter screen.

### The operating system

| Step | Action | Tools |
|---|---|---|
| 1. Source | Pull from 2 global boards + 1 regional + 1 aggregator daily | [Global Boards](#global-job-boards), [Aggregators](#job-aggregators--meta-search) |
| 2. Direct | Apply on company career page when possible (ATS priority) | [Company Pages](#company-career-pages--direct-apply) |
| 3. Network | Find hiring manager → personalized outreach + referral ask | [Networking](#networking--community) |
| 4. Track | Log every application, contact, stage, and follow-up date — manually | [Manual Tracking](#ats-optimization--manual-application-tracking) |
| 5. Prep | Tailor CV per role → prep STAR stories → mock interviews | [CV Services](#cv--resume-services), [Interview](#interview-guidelines) |
| 6. Close | Salary data + competing offers → negotiate on total comp | [Salary Research](#salary-research--compensation) |

> **No auto-submit:** steps 2–4 are manual by design. Do not use bulk-apply bots, one-click mass appliers, or "AI applies for you" services — they hurt match quality, break ATS parsing, and risk bans.

## Interview Guidelines

> Interviews test **four things**: can you do the job (skills), have you done it (evidence), will you do it here (motivation/fit), and can we work with you (collaboration). Prepare stories, not scripts — the STAR method (Situation, Task, Action, Result) is the structure interviewers listen for.

## Headhunters & Recruiting Agencies

> Agencies are **paid by the employer** (15–30% of first-year salary) — you never pay to be placed. Good recruiters are career multipliers: they know unpublished roles, coach you, and negotiate for you because their fee depends on your placement.

### How to work with headhunters
1. **Be placeable** — clear title, quantified achievements, target roles.
2. **Be responsive** — agencies prioritize candidates who reply within hours.
3. **Be exclusive per role** — don't let two agencies submit you to the same company.
4. **Give feedback** — after each intro, tell the recruiter what fit/misfit so they refine.

## Contributing

Thanks for helping keep this guide useful. Corrections and removals are as welcome as additions.

### What belongs here

This list is **production-first**. An entry should be something a job seeker or hiring team would realistically use.

**Accepted:**
- Actively maintained job boards, ATS platforms, and career services
- Recruiting agencies and headhunters with verifiable placements
- Substantive interview prep resources (courses, books, engineering writeups)
- Real hiring-domain knowledge and mental models (the primer sections)
- Open-source tools used in job search / application

**Not accepted:**
- Abandoned boards (no meaningful activity in ~12 months)
- Thin wrappers with no distinct value over what they wrap
- Marketing pages, waitlists, and unreleased products
- Paid-only content behind a signup wall with no substance
- Duplicate entries already listed under another section
- Auto-submit / bulk-apply / "AI applies for you" automation (manual-apply policy)
- LinkedIn-dependent entries (this guide stays usable with no LinkedIn account)

### Entry checklist

Before opening a pull request, confirm your entry:

1. **Is production-relevant** — something a real job seeker or recruiter would use
2. **Is actively maintained** — recent postings, releases, or doc updates
3. **Is not already listed** — search the README first
4. **Uses the canonical link** — the official site, never an aggregator or referral link
5. **Follows the table format** of the section you're adding to
6. **Has a one-line, non-marketing description** — say what it does and who it's for
7. **Sits in the most specific applicable section** — don't add a new section for a single entry

### Format

Every section uses Markdown tables. Match the columns of the section you are editing exactly.

```markdown
| [Project Name](https://example.com) ⭐ 🔓 | What it does, in one line, no hype |
```

**Badge legend** (apply only where genuinely true):

| Badge | Meaning |
|---|---|
| ⭐ | Widely adopted default for its category |
| 🔓 | Open source |
| 💰 | Commercial / paid tier required |
| ☁️ | Managed / hosted service |
| 🆓 | Free to use |
| 🏢 | Agency / service firm |
| 🎯 | Niche / specialized |

Use ⭐ sparingly — it means "if you don't have an opinion, pick this one." Roughly one to three per section.

### Submitting

```bash
git clone https://github.com/<your-username>/awesome-job.git
cd awesome-job
git checkout -b add-tool-or-section
# edit README.md
git commit -am "Add <Tool> to <Section>"
git push origin add-tool-or-section
```

### Automated checks

Every pull request runs a [lychee](https://github.com/lycheeverse/lychee) link check. If it fails, your link is unreachable — fix the URL.

```bash
# macOS
brew install lychee
lychee --config lychee.toml --no-progress .
```

Then open a pull request. Include a link, one or two sentences on why it belongs, and any affiliation disclosure.
